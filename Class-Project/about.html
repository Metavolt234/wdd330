About Uganda Travel Explorer

A responsive web application for discovering Ugandan destinations, attractions and useful travel information in one simple interface.

What you can do

  • Search and filter destinations.
  • Browse national parks, lakes, cities and cultural sites.
  • Open detailed destination information.
  • Check current weather and forecast information.
  • Save favorites on your device.

Data & technology

Destination content is organized in a local JSON dataset. Weather information is requested from Open-Meteo using destination coordinates, while REST Countries provides country reference information.
